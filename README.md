# Nachiketa Gulati portfolio

This folder is ready to publish with GitHub Pages.

## Add project media

1. Put files in `media/` using short names such as `rover-demo.gif` or `balancing-robot.mp4`.
2. In `index.html`, replace the matching `media-placeholder` block with one of:

```html
<img class="project-media" src="./media/rover-demo.gif" alt="Voice-controlled rover driving">
```

```html
<video class="project-media" controls muted playsinline poster="./media/rover-cover.jpg">
  <source src="./media/rover-demo.mp4" type="video/mp4">
</video>
```

## Publish

Copy everything in this folder to the repository used for `nachi-g.github.io`, commit, and push to the branch configured in **Settings → Pages**.

No build step or framework is required.
